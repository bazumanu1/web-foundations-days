About QuickNotes

QuickNotes gives you a simple place to capture ideas, reminders, and details as they come to mind. Keep useful information close at hand so you can get back to what you were doing.

How to use QuickNotes

  1. Open the Home page and enter a short title for your note.
  2. Write the details you want to remember in the note field.
  3. Select Add note to save your note for later.

Features

  • Quick entry for titles and note text
  • A clean, focused space for everyday reminders
  • Keyboard shortcuts for common actions

Keyboard shortcuts

Shortcut Action
Ctrl + Enter Save the current note
Ctrl + / Focus the note search field
